# Inventory Operations
Cadastro mínimo: código, descrição, grupo, fabricante/referência, unidade, localização e aplicação quando relevante.
Movimentação deve preservar data, item, quantidade e origem/destino.
Divergência de saldo deve ser explicada por ajuste, não apagada.
Produto físico deve ser associado por especificação/aplicação, não só nome comercial.
Etiquetas devem vir do cadastro mestre.
