# GitHub Delivery
Antes de commit: `git status`, `git diff`, testes/lint, segredos e arquivos indevidos.
Commits coerentes e rastreáveis.
Não executar push/merge/release/exclusão remota sem autorização explícita.
Planilhas/dados operacionais sensíveis não devem ir ao Git por conveniência; preferir template/amostra anonimizada/scripts.
