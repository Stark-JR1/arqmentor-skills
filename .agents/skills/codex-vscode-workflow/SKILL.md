# Codex + VS Code Workflow
- regras permanentes em `AGENTS.md`;
- workflows em `.agents/skills/*/SKILL.md`;
- não repetir contexto em cada prompt;
- confirmar repo/diretório;
- inspecionar antes de editar;
- mudanças pequenas;
- rodar testes/lint;
- revisar diff;
- regra recorrente deve virar contexto persistente no arquivo certo, sem duplicação.
