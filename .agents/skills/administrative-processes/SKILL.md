# Administrative Processes
Fluxo: RC -> aprovação -> PC -> fornecedor -> NF/boleto/CTE -> conferência -> fiscal/financeiro -> arquivamento.
Cada etapa: identificador, responsável, data, status, evidência e próxima ação.
Medições: cadastro separado de lançamentos; lançamento é fonte de verdade; cálculo automático; múltiplos períodos; auditoria e exceções.
