# File Organization
- definir convenção antes de renomear em massa;
- simular/dry-run quando volume for alto;
- evitar colisão e sobrescrita silenciosa;
- preservar original ou registrar mapa antigo -> novo;
- separar ENTRADA, PROCESSADOS, PENDENCIAS, RELATORIOS e LOGS quando aplicável.
