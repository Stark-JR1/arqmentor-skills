# PDF + OCR
1. verificar texto nativo;
2. extrair sem OCR quando suficiente;
3. OCR apenas em páginas necessárias;
4. manter origem/página para auditoria;
5. validar números de documento, CNPJ/CPF, valores, datas, códigos e patrimônios;
6. ambiguidade crítica vai para revisão.
