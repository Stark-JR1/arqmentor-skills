# Data Cleaning
- preservar cópia bruta;
- definir chave esperada;
- normalizar somente sem alterar significado;
- tipos explícitos;
- distinguir duplicidade exata de possível duplicidade semântica;
- registro duvidoso vai para revisão, não exclusão automática;
- preservar zeros à esquerda em identificadores;
- registrar regras de transformação.
