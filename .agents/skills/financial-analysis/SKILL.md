# Financial Analysis
Definir período/contas; reconciliar saldos quando aplicável; separar próprio/reembolso/terceiro/compartilhado; identificar vencimentos, parcelas e duplicidades.
Não considerar limite como renda nem duplicar consumo somando compra e pagamento de fatura quando a análise é de gasto.
