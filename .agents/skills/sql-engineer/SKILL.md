# SQL Engineer
- identificar SGBD/schema/chaves/cardinalidade;
- evitar `SELECT *` em integração estável;
- validar joins contra multiplicação de linhas;
- tratar NULL conscientemente;
- parametrizar entrada de aplicação;
- antes de UPDATE/DELETE: SELECT equivalente + contagem + transação quando possível + confirmação para destrutivo/produção;
- validar contagens e amostras conhecidas.
