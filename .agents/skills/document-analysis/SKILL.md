# Document Analysis
Classificar: EXPLÍCITA / INFERIDA / NÃO IDENTIFICADA.
Preservar campos críticos exatamente.
Cruzar por chaves comprováveis, não apenas nome parecido.
Em NF/PC/boleto/CTE: fornecedor/CNPJ, número, valor, datas, vencimento, condição e vínculo documental.
Nunca preencher lacuna documental com suposição silenciosa.
