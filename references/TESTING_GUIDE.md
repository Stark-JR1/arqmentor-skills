# Guia de teste

Use primeiro arquivos de cópia e cenários conhecidos. Para cada teste, registre:
- pedido;
- skill escolhida;
- decisão bloqueante feita;
- arquivo antes/depois;
- validações executadas;
- falhas da ferramenta;
- resultado.

Não promova a v2 para uso diário antes de T01, T02, T03, T04, T06 e T10 passarem pelo menos uma vez.
